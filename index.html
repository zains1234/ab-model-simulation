Bucket Rules

Bucket 0–49 → Model A (50 buckets) Bucket 50–99 → Model B (50 buckets) Input = SHA-256(Experiment ID + ":" + User ID) Bucket = Hash Number % 100

The bucket space is exactly 50/50. A finite user population will normally produce an approximate 50/50 split rather than exactly 50/50.
