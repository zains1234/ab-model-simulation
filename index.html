Deterministic A/B Model Assignment

Simulation for GTM presentation and testing

1. Configuration

Models

Add or remove models. Percentages must add up to exactly 100%.

Model Percentage Action

2. Distribution Simulation

Simulates the configured number of users and checks whether deterministic hashing produces the expected model distribution.

Run the simulation to see the result.

3. Full Consistency Test

Assigns the same users multiple times. The same user must always receive the same model when the User ID and Experiment ID remain unchanged.

Run the simulation to see the result.

4. Assignment Inspection

Shows how individual users are assigned from User ID + Experiment ID → SHA-256 Hash → Bucket → Model.

Run the simulation to see the result.
